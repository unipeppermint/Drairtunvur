# 光路工坊项目资料

版本 1.1 · 整理日期 2026 年 10 月 12 日

当前版本取消应用内购买。三章 45 关全部随应用提供，无需额外付费，按通关进度逐步开放。

《光路工坊》是一款将方块消除与光路连接结合的 iOS 解谜游戏。玩家通过拼放方块搭建光路，借消行触发充能，逐步点亮微型城市。首个里程碑交付 10 关可玩版本，正式首版为 3 章 45 关。

本套资料包含产品定义、四页高保真静态原型、原型落地说明和技术方案，可用于产品评审、美术制作与开发交接。

**首版采用以下共同基线。**

| 项目 | 统一结论 |
| --- | --- |
| 产品名称 | 光路工坊，工作名称，正式上架名称仍需检索确认 |
| 核心玩法 | 8×8 固定棋盘、三块一批、固定朝向、固定序列、有限步数 |
| 关键规则 | 消除前传光，随后清除满行满列；目标能量保留 |
| 脉冲计数 | 一次合法落子形成消除时只触发一次脉冲 |
| 内容规模 | 3 章各 15 关，共 45 关；先验证其中 10 关 |
| 页面范围 | 地图、对局、结算、图鉴，以及设置和失败反馈等必要辅助界面 |
| 内容开放 | 不接入内购，三章 45 关无需额外付费，按通关进度开放 |
| 技术栈 | Swift、UIKit、Core Animation、本地 Swift 规则模块 |
| 数据方式 | 本地关卡和存档，首版不依赖业务服务器 |
| 后续功能 | 每日任务、云存档、排行榜、公开关卡编辑器 |

**当前材料与交付状态。**

产品和技术文档已整理，四页静态原型已生成，开发对话已开始实施。可交互页面、正式分层美术、45 关内容、求解器与性能验证由开发对话交付并报告实际完成状态。

开发目标建议为 Swift 6 与 iOS 16.0 起，iPhone 竖屏优先并适配 iPad。方案制定时的工程基线为 Swift 5 语言模式和 iOS 26.5 部署目标；实际配置以工程及开发验证结果为准。部署范围与最终品牌名称在对应实施阶段确定。
