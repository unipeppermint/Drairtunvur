# 光路工坊原型说明

版本 1.1 · 整理日期 2026 年 10 月 12 日

本版取消内购。原型中的锁定节点和收藏仅表示通关进度要求，三章 45 关均无需额外付费。

[四页高保真原型图](lightworks-prototype.png)从左到右展示城市地图、光路解谜、修复完成和城市图鉴。原型由内置 imagegen 生成并经过棋盘校正，用于确认视觉方向、信息层级和页面关系；它是静态概念图，尚不具备交互。

产品行为以[产品方案](product-plan.md)为准，棋盘规则与实现边界见[技术方案](technical-plan.md)。

**城市地图承载章节进度与继续游戏入口。**

顶部显示工作名称、简短介绍与设置入口。主体为港湾微型城市场景，关卡节点沿步道分布，已完成、当前和未开放节点有明确区别。下方展示当前章节、完成数量和继续修复按钮。

| 元素 | 实际行为 |
| --- | --- |
| 继续修复 | 有有效存档时恢复对局，否则进入下一未完成关卡 |
| 已完成节点 | 进入对应关卡重玩，保留历史最好成绩 |
| 当前节点 | 进入当前开放关卡 |
| 未开放节点 | 显示解锁条件，不把点击导向空页面 |
| 设置入口 | 音效、震动、减少动画、语言及帮助 |

第一章完成后展示下一章介绍并自动开放温室，第二章完成后自动开放车站。未开放节点显示前置通关条件，不出现购买信息。地图节点与背景分层，方便不同屏幕比例下适配与点击。

**光路解谜页把棋盘和目标作为第一视觉重点。**

顶部显示章节、关卡、返回和暂停；目标区显示剩余步数与每个目标的充能刻度；中间为精确的 8×8 棋盘；下方是预览提示、三个候选方块、撤销和提示按钮。

主界面目标必须使用稳定标识、位置提示或相同图形，让目标区的信息可以对应棋盘中的目标。棋盘内目标在被方块覆盖后依然可见。

原型中的落子预览表达以下局面：第四行的前五格已占用，L 形候选填入第四行第六至第八格，以及第三行第六格。落下后第四行变满；在清除发生之前，光从第四行左侧入口传向第三行第三格和第五行第六格的两个目标，使它们各充能一次。

原型上方的 1/2 与 0/2 是落子前能量，预览“可为 2 盏灯充能”表示各加一格，不表示两个目标都会完成。正式实现由同一规则模块计算路径、受益目标和消除线。

| 状态 | 必须展示的反馈 |
| --- | --- |
| 未拖动 | 当前光路、目标能量、可用候选 |
| 合法悬停 | 幽灵形状、将清除的行列、预计充能目标 |
| 非法悬停 | 明确的无效提示，松手归位，不消耗步数 |
| 正式落子 | 落定、脉冲、充能、消除的有序短动画 |
| 动画中断 | 显示已提交最终局面，不重复计算 |
| 暂停 | 继续、重新开始、回到城市 |
| 失败 | 具体原因、撤销一步、重新挑战 |

提供点选候选后点选锚点的替代操作。减少动画模式缩短或取消非必要运动，但保留充能结果和消除反馈。

**修复完成页展示具体场景变化与关卡结果。**

主体为完成充能后亮起的港湾场景，标题对应本次修复，例如灯塔亮了。下方展示关卡使用步数、目标完成情况、章节完成数量，以及继续修复和回到城市。

使用步数来自规则状态；章节完成数量按唯一关卡 id 计算，重玩不重复增加进度。进度条长度按完成数量除以章节关卡数绘制：3/15 对应 20%。原型中的比例只作视觉示意，正式界面以实际数据为准。

**城市图鉴展示实际获得的场景收藏。**

顶部显示已收藏数量与总数，主卡展示当前章节，较小卡片展示已获得或未解锁场景。点击已获得收藏可以查看完整画面；未解锁卡片显示具体条件。

原型同时出现港湾、温室和车站，目的是展示不同主题的视觉方向，不代表同一存档当前已解锁全部章节。正式版本仅根据通关进度显示状态，数量与卡片列表保持一致。

**以下原型内容在首版落地时需要按方案处理。**

| 原型内容 | 首版落地口径 |
| --- | --- |
| 底部每日入口 | 已实现离线每日挑战，导航为城市／每日／图鉴 |
| 跨章节图鉴画面 | 按真实收藏条件解锁，不直接开放全部画面 |
| 结算进度条 | 使用真实比例，3/15 应为 20% |
| 候选块、充能和步数 | 全部由当前关卡数据和规则状态驱动 |
| 中英文内容 | 文字使用原生控件与 String Catalog，不烘焙进背景 |
| 返回、设置、失败 | 四屏图未展示的辅助界面，属于首版交付范围 |
| 购买与恢复购买 | 全部取消，不增加付费页面、商品按钮或付费锁定样式 |
| 图片中的细节和路径 | 用正式素材和程序重建，规则模块是最终依据 |

**素材制作按可复用的层拆分。**

| 素材或组件 | 交付方式 | 使用位置 |
| --- | --- | --- |
| 港湾、温室、车站背景 | 无文字的独立场景图片 | 地图、章节介绍、结算 |
| 前景与遮挡 | 透明图层 | 场景纵深与局部遮挡 |
| 建筑灯光 | 透明遮罩或局部亮灯图层 | 按修复进度逐步点亮 |
| 图鉴缩略图 | 与详情图关联的轻量图片 | 图鉴列表 |
| 棋盘与玻璃方块 | 原生格子、渐变、高光和必要纹理 | 对局 |
| 光路与脉冲 | 程序绘制路径和短动画 | 预览与充能 |
| 文字和交互控件 | UIKit 原生实现 | 全部页面 |

正式资源需要为不同显示尺寸准备适当分辨率，验证深色背景上的文字对比度和触控可用性。场景中已经绘入的文字、按钮或棋盘不能直接作为可交互界面使用。

**生成过程保留了可追溯的提示词。**

使用内置 imagegen 生成四屏概念图，随后针对第二屏棋盘的 8×8 格子、两个目标和 L 形落子预览进行校正。[初始提示词](lightworks-prototype-prompt.txt)与[校正提示词](lightworks-prototype-refinement-prompt.txt)均随资料包提供。

后续视觉修改以当前选定原型为参考，同时遵守产品与技术文档中的规则。原型不代表应用已经开发完成，也不代表关卡已通过程序求解验证。
